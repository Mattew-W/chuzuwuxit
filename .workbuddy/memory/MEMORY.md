# 出租屋系统 - 长期记忆

## 项目信息
- 项目名：收租管理系统（出租屋系统）
- 目标用户：用户的母亲（iOS + 微信）
- 技术栈：React + TypeScript + Vite + Tailwind CSS v4 + Dexie.js（IndexedDB）
- 部署方式：PWA 网页，可通过 GitHub Pages 等免费托管

## 业务数据
- 房间数：21 间（201-407 + 101铺/102铺）
- 电价：1.3 元/度
- 水价：7 元/吨
- 默认卫生费：5 元
- 结算单格式：每间房一个结算区域，包含房租/电费/水费/卫生/网线/合计

## 关键功能
- [x] 月度房间管理（录入水电读数、自动计算）
- [x] 表格式房间卡片布局（8列：房租/电本月/电上月/用电/水本月/水上月/用水/合计）
- [x] 月度结转（保存快照，读数结转）
- [x] Excel 导入导出（与原始模板兼容）
- [x] JSON 备份恢复
- [x] 结算单图片生成与分享
- [x] PWA 离线支持
- [x] Electron 打包配置（electron-builder，portable + installer）
- [x] GitHub Actions 自动部署配置
- [ ] 推送 GitHub 仓库 + 开启 Pages
- [ ] Electron EXE 编译完成

## 用户偏好
- 喜欢 Excel 表格风格的布局，不喜欢卡片式
- 信息要对齐，一眼看清
- 优先简洁直观，不要花哨
- 可以在微信里打开使用
